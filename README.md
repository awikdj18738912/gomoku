# 五子棋 · Gomoku

一个带前端界面的五子棋小游戏，支持**人机对战**与**双人对战**，无需任何第三方依赖即可运行。

## 功能特性

- 🎨 Canvas 绘制木质棋盘，黑白棋子带立体渐变效果
- 🤖 启发式 AI：棋型评分（连五/活四/冲四/活三/双威胁）+ 一层安全检查，会进攻也会防守
- 👥 双人对战模式，同一台电脑轮流落子
- ↔️ 悔棋：人机模式下可同时回退电脑一步
- 🔊 落子/胜负音效（Web Audio，可一键静音）
- 🏆 黑/白/平局战绩统计
- 📱 响应式布局，手机浏览器也可游玩

## 如何运行

方式一：直接双击打开 `index.html`（无需安装任何东西）。

方式二：本地服务器（推荐，体验更稳定）：

```bash
node server.js
# 或
npm start
```

然后浏览器访问 <http://localhost:8090>。

方式三：任何静态服务器均可，例如：

```bash
python -m http.server 8090
```

## 运行测试

```bash
npm test
```

冒烟测试覆盖：横/斜五连胜负判定、悔棋、AI 制胜手、AI 堵截、终局、AI 自对弈稳定性、非法落子等。

## 操作说明

- 人机模式下可切换“玩家执黑/执白”；执白时电脑先手
- 点击棋盘交叉点落子；悬停可见预览
- 横、竖、斜任意方向先连成五子的一方获胜
- 一局结束后点击“重新开始”继续对局（战绩保留）

## 游戏规则

标准 15×15 棋盘，黑方先行，双方轮流落子，率先在横、竖、斜任一方向连成五子者获胜；棋盘下满无五连则平局。
